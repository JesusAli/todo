Inicia sesión

La sesión se guarda en una cookie. Las actividades viven en un Markdown privado de tu cuenta de GitHub (Gist).

  1. Abre un token clásico (empieza con ghp_).
  2. Marca la casilla gist y genera el token.
  3. Pégalo aquí. La cookie dura 30 días.

Los tokens «fine-grained» (github_pat_) no funcionan: GitHub no les da acceso a Gists.
